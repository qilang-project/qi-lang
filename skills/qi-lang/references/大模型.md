# Qi LLM 语言原语（大模型编程）

Qi 把 LLM 调用做成了**语言级原语**（2026.07.10 起，2026.07.12-1 全量可用）：结构化输出、流式迭代、工具适配、嵌入都是关键字/内建，不是库函数。本文所有示例均来自仓库真实示例（`qi/示例/高级/大模型/`、`qi-harness/examples/询问*.qi` 等）。

## 会话（一切的入口）

**没有隐式默认会话**，必须显式创建。参数顺序是 **(端点URL, 模型, 密钥)**——模型在密钥前：

```qi
导入 标准库.大模型 作为 大模型;
导入 标准库.操作系统 作为 系统;

变量 会话: 整数 = 大模型.创建会话(
    系统.获取环境变量("QI_CHAT_URL"),     // OpenAI 兼容端点
    系统.获取环境变量("QI_CHAT_MODEL"),
    系统.获取环境变量("QI_CHAT_KEY"));
// 用完 大模型.关闭会话(会话)
```

- 环境变量名是**调用方约定**（示例惯用 QI_CHAT_URL/MODEL/KEY），语言不读任何环境变量。密钥绝不硬编码。
- provider 可切：`大模型.设置配置(会话, "provider", "anthropic")`（默认 openai，另支持 gemini）。
- 普通对话：`大模型.对话(会话, 提示)` 返回字符串。

## 询问::<T> —— 结构化输出（类型即 schema）

编译期从 T 派生 JSON schema，发 response_format，回复自动反序列化为强类型 T。**解析/校验失败自动带错误反馈重试 ≤2 次**（Instructor 式）：

```qi
类型 天气 {
    字符串 城市;
    整数 温度;
    字符串 状况;
}

变量 天: 天气 = 询问::<天气>(会话, "东京现在的天气，虚构合理数据即可");
打印行(模板"{天.城市} {天.温度}度 {天.状况}");
```

**T 支持的字段深度**（全部有真实示例）：

| 字段类型 | 说明 |
|---|---|
| 标量 整数/浮点数/字符串/布尔 | 直接映射 |
| 无载荷枚举 | 分类任务：模型选变体名，回来是枚举值，可 `匹配` |
| **带载荷枚举** | **分类+提取合一**：`枚举 审核结果 { 通过, 驳回(字符串), 需补材料(字符串) }`——模型判类别的同时抽取载荷，`匹配` 解构 `驳回(原因) =>` |
| 嵌套结构体 | 递归支持（嵌套 >5 层编译报错，疑似自引用） |
| 数组 | `数组<字符串>`/`数组<整数>`/数组of结构体 都行 |
| `选项<T>` 可选字段 | 缺键或 null → `无`，有值 → `有(值)`；**v1 内层仅限标量** |

内建 `选项<T>{有(T),无}` 的构造用裸构造子 `有(42)`/`无`；用户枚举构造带类型名 `审核结果.驳回("材料不全")`。

含数组字段的结构体走 json_object+提示（非 strict json_schema，规避部分模型改写中文数组的兼容问题），行为不变。

## 尝试询问 / 异步询问

```qi
// 失败不炸：返回 结果<T, 字符串>（败 带原始回复）
匹配 尝试询问::<城市信息>(会话, "北京的城市名和大概人口") {
    成(c) => { 打印行(c.名称); }
    败(e) => { 打印行("解析失败: " + e); }
}

// 真并行：立即发请求（HTTP 独立线程在飞），等待 时才解码
变量 f: 未来<人物> = 异步询问::<人物>(会话1, "介绍鲁迅");
变量 g: 未来<人物> = 异步询问::<人物>(会话2, "介绍老舍");
变量 p: 人物 = 等待 f;    // 两问耗时 ≈ 单问
变量 q: 人物 = 等待 g;
```

注意：`异步询问` v1 **没有**校验反馈重试（同步 `询问`/`尝试询问` 才有）。并行时给每路开独立会话。

## 工具模式 / 工具适配 —— 签名即工具

给定一个普通函数，`工具模式(函数名)` 编译期从签名生成 OpenAI tool 参数 schema（JSON 字符串），`工具适配(函数名)` 生成 `函数(字符串):字符串` 适配器（JSON 实参 → 类型化形参 → 调用）。配合 qi-harness 的 agent 工具循环零胶水：

```qi
函数 查天气(城市: 字符串, 单位: 字符串) : 字符串 {
    返回 "{\"城市\":\"" + 城市 + "\",\"温度\":18}";
}

代理值 = 添加工具(代理值, 新建 工具 {
    名字: "查天气",
    描述: "查询指定城市的天气",
    参数schema: 工具模式(查天气),
    处理: 工具适配(查天气),
});
```

v1 约束：工具函数**必须返回 字符串**，形参**仅限标量**（整数/浮点数/字符串/布尔）。

## 流式 —— 一等流迭代

```qi
对于 片段 在 流式(会话, "用一句话介绍北京") {
    打印(片段);           // token 级片段，循环结束自动关流
}
```

也可拿句柄手动驱动：`变量 s: 整数 = 流式(会话, 提示);` 然后循环 `大模型.读取流(s)`（空串=结束），`大模型.关闭流(s)`。

## 嵌入 与 相似度

```qi
变量 嵌会话 = 大模型.创建会话(URL, "text-embedding-v4", 密钥);   // 嵌入模型的会话
变量 v1: 数组<浮点数> = 嵌入(嵌会话, "我爱吃苹果");
变量 v2: 数组<浮点数> = 嵌入(嵌会话, "苹果很好吃");
变量 近: 浮点数 = 相似度(v1, v2);      // 余弦相似度
```

端点打 `<base>/embeddings`。（qi-harness 另有 `向量记忆.余弦相似度(JSON串, JSON串)`，是不同的库函数。）

## 填充模板 —— 编译期模板

```qi
变量 提示 = 填充模板("规划 {城市} 的 {天数} 日游", 城市, 整数转字符串(天数));
```

首参必须是字符串**字面量**，洞数编译期校验，实参按位置、须已是字符串。三种模板别混淆：

| 机制 | 时机 | 形式 |
|---|---|---|
| `填充模板(字面量, 实参…)` | 编译期洞校验 | 位置参数 |
| `模板"…{任意表达式}…"` | 运行时插值字符串 | 花括号内任意表达式 |
| `Harness.提示模板`(提取变量/填充/校验填充) | 运行时库 | 命名 `{变量}` + JSON 值 |

## 预算

**没有 `在预算(){}` 块语法**。预算是会话级运行时强制：

```qi
大模型.设置预算(会话, 5000);        // token 硬上限，0=不限
// 超限后调用不打 API，直接返回含 "预算超限" 的错误串
打印行(大模型.已用预算(会话));
```

（qi-harness 另有 `预算` 模块：创建预算/记入成本/超预算/预算报告，token+成本双上限的库级账本。）

## 磁带（录制/回放/缓存）—— 零代码改动

同一份 `询问`/`对话`/`嵌入`/`流式` 代码，用环境变量切换真调/回放：

```bash
QI_LLM_RECORD=1 QI_LLM_TAPE=t.json qi run 程序.qi   # 真调 API 并落盘
QI_LLM_REPLAY=1 QI_LLM_TAPE=t.json qi run 程序.qi   # 只回放，miss 报「磁带回放未命中」
QI_LLM_CACHE=1  QI_LLM_TAPE=t.json qi run 程序.qi   # 命中用磁带，miss 真调并回写
```

`QI_LLM_TAPE` 缺省 `llm_tape.json`；流式与嵌入共用同一磁带文件。CI/课堂判分用 REPLAY 保证确定性与零费用。
