# Qi 并发与异步

**真协程默认开启（2026.07.12 起）**：「返回 `未来<T>` 且含 `等待`」的函数被编译成 LLVM coroutine（`llvm.coro.*` stackless 状态机），由多核 M:N 执行器调度——默认 worker 数 = CPU 逻辑核数，`QI_CORO_WORKERS` 可覆盖；`QI_CORO=0` 退回 eager future（调试用）。门控是**函数级**：不含 `未来<T>+等待` 的普通程序 IR 逐字节不变、性能零回退。

协程模式下通道走原生实现（park-wake 背压 + **死锁检测**：全体协程挂起且无人唤醒时报错不 hang）。微基准（M2 Pro，vs Go 1.26）：上下文切换 100 万 2.6 倍胜、通道收发/协程创建小胜、高扇入汇聚大胜；纯 CPU 密集小负载暂负于 Go（编译器优化档位问题，非调度器）。

goroutine（`启动`）跑在多线程运行时上（worker 数可用 `QI_ASYNC_WORKERS` 调）。

## 启动（goroutine）

语法只有一种：`启动 函数调用(实参...);`。**没有 `启动 { ... }` 块形式**（解析报错）。

```qi
包 主程序;

导入 标准库.时间;

函数 干活(编号: 整数) {
    打印行("工人" + 整数转字符串(编号) + "完成");
}

函数 入口() {
    启动 干活(1);
    启动 干活(2);
    时间.睡眠毫秒(100);   // 简单 join；可靠 join 用等待组，见下
}
```

主协程退出即整个进程退出，不会等 goroutine——必须用 睡眠/等待组/通道 收尾。

## 通道

创建 `通道<整数>()`（无缓冲）或 `通道<整数>(容量)`；发送 `信道 <- 值`；接收 `<- 信道`（阻塞）。`通道<字符串>`/`通道<浮点数>`/`通道<布尔>` 也已解锁（2026.07.05-1 起）。

```qi
包 主程序;

函数 生产者(信道: 通道<整数>) {
    信道 <- 42;
}

函数 入口() {
    变量 信道 = 通道<整数>();
    启动 生产者(信道);
    变量 值 = <- 信道;      // 阻塞直到有值
    打印行(值);             // 42
}
```

- **协程上下文**（未来<T>+等待 的函数内）：通道满/空会「让出+挂起」，协作式不占线程，有真背压。
- **非协程上下文**（顶层、普通函数）：带缓冲通道按非阻塞轮询工作，别依赖背压。
- **`选择`（select）可用**：非阻塞轮询多通道，支持 `默认` 分支（无就绪立即走，Go 语义）与 `超时(毫秒)` 分支；两者皆无则阻塞轮询。通道表达式只求值一次。

```qi
选择 {
    情况 v := <-通道甲:
        打印行("收到: " + 整数转字符串(v));
    情况 超时(500):
        打印行("超时分支");
    默认:
        打印行("默认分支");
}
```

注意:分支是 **Go 风格冒号语法**(`情况 ...:` 后跟语句),不是 匹配 的 `=>` 块。

## 未来<T> 与 等待

异步函数 = 返回类型标注 `未来<T>` 的普通函数（返回值自动包成 Future）。`等待 表达式` 取值。支持 `未来<整数>`/`未来<浮点数>`/`未来<布尔>`/`未来<字符串>`：

```qi
包 主程序;

导入 标准库.时间;

函数 慢计算(x: 整数): 未来<整数> {
    时间.睡眠毫秒(50);
    返回 x * x;
}

函数 入口() {
    变量 甲 = 慢计算(3);          // 立即返回 future，两个并发跑
    变量 乙 = 慢计算(4);
    变量 和 = 等待 甲 + 等待 乙;   // 等待 是一元前缀表达式
    打印行(和);                    // 25
    变量 直取: 整数 = 等待 慢计算(5);  // 也可直接 等待 函数调用()
    打印行(直取);
}
```

静态构造：`未来::就绪(值)`、`未来::失败("消息")`。

### 让出与执行器（协程模式）

协程函数内可显式让出调度点：`等待 让出();`（`让出` 是内建函数，配 `等待` 用）。`等待 异步睡眠(毫秒)` 是挂起式睡眠（不占 worker 线程）。`执行器运行全部()` 驱动执行器把已创建的 future 全部跑完（拿到多个 future 后统一推进的写法，见 `qi/示例/高级/协程/`）：

```qi
变量 甲未来: 未来<整数> = 甲();   // 跑到首个挂起点即让出
变量 乙未来: 未来<整数> = 乙();
执行器运行全部();                 // 两协程交错推进到完成
变量 甲值: 整数 = 等待 甲未来;
```

### future 出错经 等待 传播

async 函数内 `抛出` 的异常在 `等待` 处重新抛出，可被外层 `尝试/捕获` 接住：

```qi
函数 可能失败(x: 整数): 未来<整数> {
    如果 x < 0 {
        抛出 "输入不能为负";
    }
    返回 x * 2;
}

函数 入口() {
    尝试 {
        变量 值 = 等待 可能失败(-1);
        打印行(值);
    } 捕获 错误 {
        打印行("等待时捕获: " + 错误);   // 等待时捕获: 输入不能为负
    }
}
```

## goroutine 内异常

`抛出` 是 setjmp/longjmp、线程内传播——goroutine 里未捕获的异常**不会**打断主协程，而是进全局异常队列，由主协程主动查询（这些是全局内建函数，无需导入）：

```qi
包 主程序;

导入 标准库.时间;

函数 协程崩溃() {
    抛出 "协程内部错误";
}

函数 入口() {
    启动 协程崩溃();
    时间.睡眠毫秒(100);
    变量 数量 = 协程异常数量();          // 队列中的异常个数
    如果 数量 > 0 {
        变量 消息 = 获取协程异常();       // 取出一条（出队）
        打印行("异常内容: " + 消息);
    }
}
```

带句柄的形式：`启动并等待协程(函数)` 返回句柄，配 `等待协程(句柄)`、`协程有异常(句柄)`、`获取协程异常句柄(句柄)`。

## 同步原语（标准库.同步）

句柄式函数 API（不是方法式）。

### 原子计数

```qi
包 主程序;

导入 标准库.同步;
导入 标准库.时间;

变量 计数句柄: 整数 = 0;

函数 工人() {
    变量 i = 0;
    当 i < 1000 {
        同步.原子加(计数句柄, 1);    // 返回旧值
        i = i + 1;
    }
}

函数 入口() {
    计数句柄 = 同步.创建原子(0);     // 注意：必须带初值参数
    启动 工人();
    启动 工人();
    启动 工人();
    启动 工人();
    时间.睡眠毫秒(500);
    打印行(同步.读原子(计数句柄));   // 4000，无竞争
}
```

### 互斥锁

`同步.创建锁()` → `加锁(句柄)` / `尝试加锁(句柄)`（占用返回 0）/ `解锁(句柄)` / `销毁锁(句柄)`。

### 等待组（可靠 join，全局内建）

```qi
包 主程序;

函数 干活(组: 整数, 编号: 整数) {
    打印行("工人" + 整数转字符串(编号) + "完成");
    完成(组);
}

函数 入口() {
    变量 组 = 创建等待组();
    添加等待(组, 3);
    启动 干活(组, 1);
    启动 干活(组, 2);
    启动 干活(组, 3);
    等待组等待(组);          // 阻塞到 3 个 完成
    打印行("全部完成");
}
```

别名：创建等待组/新建等待组；添加等待/等待组增加/等待组添加；完成/等待组完成。

## 打印与并发

单次 `打印行(单个字符串)` 是行级原子的（底层一次 println 调用）。**多参 `打印行(a, b, c)` 编译成多次独立运行时调用**——参数之间会被其他 goroutine 的输出交错，且每参各带换行。并发程序里永远先 `+` 拼成一个字符串再打印。

## 环境变量速查

| 变量 | 作用 |
|---|---|
| `QI_CORO=0` | 关真协程，退 eager future（默认开） |
| `QI_CORO_WORKERS=N` | 协程执行器 worker 数（默认 = CPU 逻辑核数） |
| `QI_ASYNC_WORKERS=N` | goroutine 运行时 worker 线程数 |
