# Qi 语法参考

所有代码块均在 qi 2026.07.04-1 上实际 `qi run` 验证通过。标点同时支持英文 `; : ( ) { } ,` 与中文 `； ： （ ） 【 】 ，`（但全角 `＝` 不行，赋值只能用半角 `=`）。注释用 `//` 与 `/* */`（块注释可嵌套，2026.07.04 起）。字符字面量支持转义：`'\n' '\t' '\r' '\\' '\'' '\0'`（2026.07.04 起）。

## 变量、常量与基础类型

```qi
包 主程序;

函数 入口() {
    变量 名字 = "Qi";           // 可变，类型推断
    变量 年龄: 整数 = 10;       // 显式类型
    常量 PI = 3.14159;          // 不可变，必须初始化
    变量 激活: 布尔 = 真;       // 布尔字面量：真 / 假
    变量 温度: 浮点数 = 36.5;
    打印行(名字);
    打印行(年龄);
}
```

| 类型 | 含义 | LLVM |
|---|---|---|
| `整数` | **默认 64 位**有符号 | i64 |
| `浮点数` | 64 位浮点 | double |
| `字符串` | UTF-8（指针，ARC 管理） | ptr |
| `布尔` | `真`/`假` | i1 |
| `空` | 无返回值 | void |

FFI 布尔型函数（如 `文本.包含`）返回整数 `1`/`0`，判断写 `== 1`。

全局常量/变量支持，顶层声明，函数内可直接读写：

```qi
常量 端口: 整数 = 43719;
常量 主机 = "127.0.0.1";
变量 计数器: 整数 = 0;

函数 增加() { 计数器 = 计数器 + 1; }

函数 入口() {
    打印行(主机 + ":" + 端口);
    增加();
    打印行(计数器);   // 1
}
```

## 控制流

### 如果 / 否则

```qi
如果 x > 10 {
    打印行("大于10");
} 否则 {
    打印行("其他");
}
```

else-if 链的真实语法是 `否则如果` 后**再写一个 如果**（LALR 语法的怪产物），且链尾必须有 `否则`：

```qi
如果 x > 10 {
    打印行("大");
} 否则如果 如果 x > 5 {
    打印行("中");
} 否则 {
    打印行("小");
}
```

推荐写嵌套 `否则 { 如果 ... }`，可读性更好也不易踩坑。

### 当（while）——唯一的计数循环手段

```qi
变量 i = 0;
当 i < 10 {
    i = i + 1;
}
```

- **没有** `0..10` 区间语法（`对于 i 在 0..3` 解析报错）。
- **没有** `循环 {}`（关键字保留但语法未实现）。
- **区间循环**（2026.07.04 起）：`对于 i 在 0..10 {}` 半开、`对于 i 在 0 到 9 {}` 闭区间（含端点）；起止任意整数表达式各求值一次，空区间零次。
- **位运算**（2026.07.04 起）：`& | ^ << >>` 仅整数，优先级 Go 风格（`<< >> &` 随乘除、`| ^` 随加减）。
- **`跳出`/`继续` 可用**（2026.07.03 起）：`当` 与 `对于` 循环体内均有效，`继续` 在 `对于` 中会正确步进不死循环；嵌套循环只作用于最内层；循环体外使用是编译错误。

### 对于 ... 在（仅数组遍历）

```qi
变量 数列 = [10, 20, 30];
对于 x 在 数列 {
    打印行(x);
}
对于 n 在 [1, 2, 3] { 打印行(n); }   // 字面量也行；也用于遍历变参
```

### 枚举（2026.07.04-2 起）

```qi
枚举 颜色 { 红, 绿, 蓝 }                          // 无载荷:整数 tag,== 可比,零分配
枚举 形状 { 圆(浮点数), 矩形(浮点数, 浮点数), 点 }  // 任一变体带载荷 ⇒ 整个枚举装箱(ARC 回收)

变量 c: 颜色 = 颜色.绿;
变量 形 = 形状.圆(2.0);
匹配 形 {
    圆(半径) => { 打印行(浮点数转字符串(半径)); }   // 解构绑定,可配守卫
    矩形(宽, 高) => { }
    点 => { }                                     // 穷尽性强制:缺分支编译报错,_ 兜底豁免
}
```

变体名不能用保留字(如 空);枚举目标只能用变体分支,非枚举目标不能用变体分支(均人话报错)。

### 匹配（match）

2026.07.03 起可用（此前静默无效）。支持整数/浮点/布尔/字符/字符串字面量分支、守卫、`_` 通配、变量绑定兜底；裸块即语句（结尾分号可选）；全分支 `返回/抛出` 时函数尾无需再补返回；**只能作语句**（`变量 x = 匹配 ...` 是解析错误）。不支持的模式（结构体解构、或模式 `2 | 3`——lexer 无 `|`）会编译报错而非静默。

```qi
函数 描述(n: 整数): 字符串 {
    匹配 n {
        1 => { 返回 "壹"; }
        k 如果 k > 100 => { 返回 "大数"; }   // 守卫
        _ => { 返回 "其他"; }
    }
}
```

字符串同样可匹配（内部用运行时比较）：`匹配 s { "你好" => { ... } _ => { ... } };`

## 函数

```qi
函数 加法(x: 整数, y: 整数): 整数 {
    返回 x + y;
}

函数 打招呼(名字: 字符串) {          // 无返回值可省 : 类型
    打印行("你好，" + 名字);
}

// 默认参数
函数 问候(名字: 字符串, 前缀: 字符串 = "您好") {
    打印行(前缀 + "，" + 名字);
}

// 变参：名字...: 类型 —— 收成数组，只能是最后一个参数
函数 求和(数字...: 整数): 整数 {
    变量 总 = 0;
    对于 n 在 数字 { 总 = 总 + n; }
    返回 总;
}

函数 入口() {
    问候("张三");             // 您好，张三
    问候("李四", "早上好");    // 早上好，李四
    打印行(求和(1, 2, 3, 4, 5));  // 15
}
```

### 函数作为值 / 闭包

函数类型标注写 `函数(参数类型,...): 返回类型`。具名函数直接按名传递；闭包用 `闭包(参数): 返回类型 { ... }`：

```qi
函数 应用(f: 函数(整数): 整数, x: 整数): 整数 {
    返回 f(x);
}

函数 翻倍(x: 整数): 整数 { 返回 x * 2; }

函数 入口() {
    打印行(应用(翻倍, 10));    // 20 —— 具名函数作值
    变量 基数 = 100;
    变量 加基数 = 闭包(x: 整数): 整数 {
        返回 x + 基数;         // 捕获外层变量（闭包环境受 ARC 管理）
    };
    打印行(应用(加基数, 5));   // 105
    打印行(应用(闭包(x: 整数): 整数 { 返回 x * 10; }, 7));  // 70 内联闭包
}
```

**坑**：闭包存进变量后**直接调用**（`加基数(5)`）报「未定义的函数」——闭包值必须作为 `函数(...)` 类型参数传给函数后才能调。

## 结构体与方法

字段声明是 `类型 字段;` 风格（C 式，分号结尾）。方法是 Go 风格接收者，接收者名可用 `自己`/`自身`：

```qi
类型 用户 {
    字符串 姓名;
    整数 年龄;
}

函数 (自己 用户) 简介(): 字符串 {
    返回 自己.姓名 + "(" + 自己.年龄 + "岁)";
}

函数 入口() {
    变量 甲 = (用户 { 姓名: "张三", 年龄: 30 });  // 字面量必须括号包裹
    打印行(甲.简介());     // 张三(30岁)
    甲.年龄 = 31;          // 字段赋值 OK
    变量 乙 = 新建 用户 { 姓名: "李四", 年龄: 25 };  // 新建 形式不用括号
    打印行(乙.姓名);
}
```

方法可带参数、可返回结构体（返回结构体字面量同样要括号包裹）：

```qi
函数 (自己 点) 平移(dx: 浮点数, dy: 浮点数): 点 {
    返回 (点 { x: 自己.x + dx, y: 自己.y + dy });
}
```

`枚举` 是保留字但未实现——用整数常量模拟（`常量 红色: 整数 = 1;`）。

## 异常处理

`尝试/捕获/最终/抛出` 完整可用（setjmp/longjmp 实现，同线程内跨函数传播）。抛出的是字符串表达式：

```qi
函数 除法(a: 整数, b: 整数): 整数 {
    如果 b == 0 {
        抛出 "除数不能为零";
    }
    返回 a / b;
}

函数 入口() {
    尝试 {
        变量 商 = 除法(10, 0);
        打印行(商);
    } 捕获 错误 {                       // 捕获 变量名（任意标识符）
        打印行("捕获到异常: " + 错误);
        尝试 {
            抛出 "重新抛出的" + 错误;    // 捕获块内可再抛/再套 尝试
        } 捕获 错误二 {
            打印行("再捕获: " + 错误二);
        }
    } 最终 {
        打印行("清理完成");             // 最终 可选
    }
}
```

未捕获的 `抛出` 打印「未捕获的异常」并 abort。goroutine/future 中的异常见 [并发异步.md](并发异步.md)。

## 数组

```qi
变量 数列 = [64, 34, 25, 12];
打印行(数列[0]);      // 读下标 OK
打印行(数列.长度);     // 4 —— .长度 属性
对于 n 在 数列 { ... }  // 遍历 OK
```

**`数列[1] = 99` 不支持**（codegen 报「暂只支持标识符 / 字段赋值」）。需要可变序列用 `标准库.列表`：

```qi
导入 标准库.列表 作为 列表库;   // 「列表」是类型关键字，必须起别名

变量 表 = 列表库.创建整数列表();
列表库.添加整数(表, 64);
列表库.设置整数(表, 0, 99);
打印行(列表库.获取整数(表, 0));
列表库.删除列表(表);
```

哈希表无字面量语法，见 [标准库.md](标准库.md) 的 哈希表 模块。

## 字符串

拼接用 `+`，任一侧是字符串即可直接拼数字：

```qi
打印行("年龄: " + 30);          // 年龄: 30
打印行("圆周率: " + 3.14);      // 圆周率: 3.14
```

- `打印行(a, b, c)` 逗号多参**逐参各占一行**，不要用；拼成单串。
- `f"名字={名字}"` 能解析但 codegen 失败（「打印实参无值」），不要用。
- 类型转换内建（唯一可靠方式，`作为` 转换不生成代码）：

```qi
整数转字符串(42)      // "42"
浮点数转字符串(3.7)   // "3.7"
字符串转整数("123")   // 123
字符串转浮点数("1.25") // 1.25
浮点数转整数(3.7)     // 3（截断）
整数转浮点数(2)       // 2.0
```

其余操作（查找/子串/替换/分割…）在 `标准库.文本`，注意**子串按字节索引**（中文 3 字节/字，切错边界会 panic）。

## 导入

```qi
导入 标准库.HTTP;                       // 标准库模块（大写 HTTP）
导入 标准库.输入输出 作为 IO;            // 别名（注意坑 9：返回字符串要显式标注类型）
导入 标准库.列表 作为 列表库;            // 类型关键字模块必须别名
导入 ./辅助;                            // 相对路径（同目录 辅助.qi）
导入 ../工具包;                         // 上级目录
导入 工具::{平方, 问好};                 // 第三方包 destructure（唯一跨包调用方式）
公开 导入 桩;                           // 重导出
```

- 模块函数调用用 `.`：`HTTP.获取(...)`。跨包只支持 destructure 导入后直呼函数名，**不支持** `Web::函数()`。
- `字符串` 是类型关键字，字符串模块用 `标准库.文本`。

## 保留字地雷

不能作变量/函数/字段名（报「是奇语保留关键字」或解析错）：

```
结果 类型 选项 通道 未来 数组 列表 字典 集合 任务 循环
尝试 捕获 抛出 最终 返回 等待 异步 新建 选择 情况 在 作为
与 或 非 加 减 乘 除 取余 等于 不等于 大于 小于
整数 浮点数 字符串 布尔 字节 字符 指针 引用 枚举 结构体 方法
```

- 中文直觉命名最常踩：`变量 结果 = ...`、`变量 乘 = ...`、`变量 数组 = ...` 全报错。改 `计算结果`/`乘法函数`/`数列`。
- 例外：`长度` 可作标识符；`类型 通道 结果 选项` 可作**字段名**；接收者名可用 `自己/自身/自我`。
