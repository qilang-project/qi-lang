# Qi 并发与异步

goroutine 跑在全局 tokio 多线程运行时上（worker 数 = CPU 核数，可用环境变量 `QI_ASYNC_WORKERS` 调）。代码块均实测通过（2026.07.03-1）。

## 启动（goroutine）

语法只有一种：`启动 函数调用(实参...);`。**没有 `启动 { ... }` 块形式**（解析报错）。

```qi
包 主程序;

导入 标准库.时间;

函数 干活(编号: 整数) {
    打印行("工人" + 编号 + "完成");
}

函数 入口() {
    启动 干活(1);
    启动 干活(2);
    时间.睡眠毫秒(100);   // 简单 join；可靠 join 用等待组，见下
}
```

主协程退出即整个进程退出，不会等 goroutine——必须用 睡眠/等待组/通道 收尾。

## 通道

创建 `通道<整数>()`（无缓冲）或 `通道<整数>(容量)`；发送 `信道 <- 值`；接收 `<- 信道`（阻塞）。

```qi
包 主程序;

函数 生产者(信道: 通道<整数>) {
    信道 <- 42;
}

函数 入口() {
    变量 信道 = 通道<整数>();
    启动 生产者(信道);
    变量 值 = <- 信道;      // 阻塞直到有值
    打印行(值);             // 42
}
```

坑：

- **只有 `通道<整数>` 可用**。`通道<字符串>`/`通道<浮点数>` 发送时 LLVM 校验失败。传字符串需借哈希表/JSON 句柄（句柄是整数）中转。
- 容量参数只是元数据，底层是无界队列——发送永不阻塞，别依赖背压。
- **`选择`（select）可用**（2026.07.03 起）：非阻塞轮询多通道，支持 `默认` 分支（无就绪立即走，Go 语义）与 `超时(毫秒)` 分支（到期走）；两者皆无则阻塞轮询至有通道就绪。通道表达式只求值一次。

```qi
选择 {
    情况 v := <-通道甲:
        打印行("收到: " + 整数转字符串(v));
    情况 超时(500):
        打印行("超时分支");
    默认:
        打印行("默认分支");
}
```

注意:分支是 **Go 风格冒号语法**(`情况 ...:` 后跟语句),不是 匹配 的 `=>` 块。

## 未来<T> 与 等待

异步函数 = 返回类型标注 `未来<T>` 的普通函数（返回值自动包成 Future）。`等待 表达式` 取值。支持 `未来<整数>`/`未来<浮点数>`/`未来<布尔>`/`未来<字符串>`：

```qi
包 主程序;

导入 标准库.时间;

函数 慢计算(x: 整数): 未来<整数> {
    时间.睡眠毫秒(50);
    返回 x * x;
}

函数 入口() {
    变量 甲 = 慢计算(3);          // 立即返回 future，两个并发跑
    变量 乙 = 慢计算(4);
    变量 和 = 等待 甲 + 等待 乙;   // 等待 是一元前缀表达式
    打印行(和);                    // 25
    变量 直取: 整数 = 等待 慢计算(5);  // 也可直接 等待 函数调用()
    打印行(直取);
}
```

静态构造：`未来::就绪(值)`、`未来::失败("消息")`。

### future 出错经 等待 传播

async 函数内 `抛出` 的异常在 `等待` 处重新抛出，可被外层 `尝试/捕获` 接住：

```qi
函数 可能失败(x: 整数): 未来<整数> {
    如果 x < 0 {
        抛出 "输入不能为负";
    }
    返回 x * 2;
}

函数 入口() {
    尝试 {
        变量 值 = 等待 可能失败(-1);
        打印行(值);
    } 捕获 错误 {
        打印行("等待时捕获: " + 错误);   // 等待时捕获: 输入不能为负
    }
}
```

## goroutine 内异常

`抛出` 是 setjmp/longjmp、线程内传播——goroutine 里未捕获的异常**不会**打断主协程，而是进全局异常队列，由主协程主动查询（这些是全局内建函数，无需导入）：

```qi
包 主程序;

导入 标准库.时间;

函数 协程崩溃() {
    抛出 "协程内部错误";
}

函数 入口() {
    启动 协程崩溃();
    时间.睡眠毫秒(100);
    变量 数量 = 协程异常数量();          // 队列中的异常个数
    如果 数量 > 0 {
        变量 消息 = 获取协程异常();       // 取出一条（出队）
        打印行("异常内容: " + 消息);
    }
}
```

带句柄的形式：`启动并等待协程(函数)` 返回句柄，配 `等待协程(句柄)`、`协程有异常(句柄)`、`获取协程异常句柄(句柄)`。

## 同步原语（标准库.同步）

句柄式函数 API（不是方法式）。

### 原子计数

```qi
包 主程序;

导入 标准库.同步;
导入 标准库.时间;

变量 计数句柄: 整数 = 0;

函数 工人() {
    变量 i = 0;
    当 i < 1000 {
        同步.原子加(计数句柄, 1);    // 返回旧值
        i = i + 1;
    }
}

函数 入口() {
    计数句柄 = 同步.创建原子(0);     // 注意：必须带初值参数
    启动 工人();
    启动 工人();
    启动 工人();
    启动 工人();
    时间.睡眠毫秒(500);
    打印行(同步.读原子(计数句柄));   // 4000，无竞争
}
```

### 互斥锁

`同步.创建锁()` → `加锁(句柄)` / `尝试加锁(句柄)`（占用返回 0）/ `解锁(句柄)` / `销毁锁(句柄)`。

### 等待组（可靠 join，全局内建）

```qi
包 主程序;

函数 干活(组: 整数, 编号: 整数) {
    打印行("工人" + 编号 + "完成");
    完成(组);
}

函数 入口() {
    变量 组 = 创建等待组();
    添加等待(组, 3);
    启动 干活(组, 1);
    启动 干活(组, 2);
    启动 干活(组, 3);
    等待组等待(组);          // 阻塞到 3 个 完成
    打印行("全部完成");
}
```

## 打印与并发

单次 `打印行(单个字符串)` 是行级原子的（底层一次 println 调用）。**多参 `打印行(a, b, c)` 编译成多次独立运行时调用**——参数之间会被其他 goroutine 的输出交错，且每参各带换行。并发程序里永远先 `+` 拼成一个字符串再打印。
