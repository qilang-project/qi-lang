# Qi 标准库参考

权威来源为编译器注册表 `qi/src/codegen/module_registry.rs`（约 30+ 模块、500+ 函数）；本文挑每模块高频核心 API。代码块均实测通过（最后核对 2026.07.12-1）。

通用规则：

- 导入 `导入 标准库.模块名;`，调用 `模块名.函数(...)`。
- 模块几乎都以「裸名 + `标准库.` 前缀」双注册。别名映射：字符串→**文本**、时间→日期、操作系统→OS、大模型→LLM、图形化→GUI。
- `列表`/`数组`/`字典`/`集合` 是类型关键字，对应模块**必须**起别名：`导入 标准库.列表 作为 列表库;`。
- 用户 `作为` 别名后，返回字符串的调用赋给变量要加 `: 字符串` 标注（类型推断丢失，打印会出指针数字）。

## 返回值约定（FFI 踩坑表）

| 函数族 | 成功 | 失败 |
|---|---|---|
| `读取文件`、字符串函数(去空白/替换…) | 结果 | **空串 ""**（用 `文本.字节长度(x) == 0` 判断） |
| `写入文件`/`追加文件`/`删除文件`/目录操作 | `1` | `0` |
| 布尔型（`包含`/`文件存在`/`是否匹配`/`存在`…） | `1`(真) | `0`(假) |
| `文本.查找` | 字节位置 | `-1` |
| `文件大小` | 字节数 | `-1` |
| HTTP 方法 | 响应体 | 内容为 `"HTTP错误: ..."` 的字符串 |
| 句柄构造（JSON/列表/哈希表/服务器/子进程…） | 整数句柄（后续操作首参） | — |

约定不完全统一，用前对表。

## 输入输出（文件与打印）

```qi
导入 标准库.输入输出;

输入输出.写入文件("/tmp/演示.txt", "第一行\n");   // 1=成功
输入输出.追加文件("/tmp/演示.txt", "第二行\n");
变量 内容 = 输入输出.读取文件("/tmp/演示.txt");   // 失败返回 ""
打印行(内容);
打印行(输入输出.文件存在("/tmp/演示.txt"));       // 1
打印行(输入输出.文件大小("/tmp/演示.txt"));       // 字节数；不存在 -1
输入输出.删除文件("/tmp/演示.txt");
```

另有：`创建文件` `创建目录` `删除目录` `创建符号链接`。`打印`/`打印行` 是全局内建，无需导入。

## 文本（字符串操作）

```qi
导入 标准库.文本;

变量 s = "  你好，Qi 世界  ";
变量 干净 = 文本.去空白(s);
打印行(文本.字节长度(干净));        // UTF-8 字节数
打印行(文本.字符数量(干净));        // 字符数
打印行(文本.包含(干净, "世界"));    // 1
打印行(文本.替换(干净, "世界", "宇宙"));
打印行(文本.转大写("hello"));       // HELLO；转小写 同理
打印行(文本.查找(干净, "Qi"));      // 字节位置；未找到 -1
打印行(文本.子串("你好世界", 0, 6)); // 你好 —— 按字节！切错边界 panic
```

`分割` 返回**字符串列表句柄**，配合列表模块读取：

```qi
导入 标准库.文本;
导入 标准库.列表 作为 列表库;

变量 句柄 = 文本.分割("苹果,香蕉,樱桃", ",");
变量 个数 = 列表库.字符串列表大小(句柄);
变量 i = 0;
当 i < 个数 {
    打印行(列表库.获取字符串(句柄, i));
    i = i + 1;
}
```

另有：`开始于` `结束于` `等于` `查找从位置` `子串从位置`。

## JSON

句柄式 API。`创建对象/创建数组` 返回句柄，用完 `删除` 释放：

```qi
导入 标准库.JSON;

变量 用户 = JSON.创建对象();
JSON.设置字符串(用户, "姓名", "张三");
JSON.设置整数(用户, "年龄", 30);
JSON.设置布尔(用户, "活跃", 1);
变量 标签 = JSON.创建数组();
JSON.数组添加字符串(标签, "工程师");
JSON.设置数组(用户, "标签", 标签);
打印行(JSON.转字符串(用户));   // {"姓名":"张三","年龄":30,"活跃":true,"标签":["工程师"]}
// JSON.格式化(句柄) 为带缩进版本

变量 句柄 = JSON.解码("{\"城市\":\"北京\",\"人口\":2154}");  // 解析
打印行(JSON.获取字符串(句柄, "城市"));
打印行(JSON.获取整数(句柄, "人口"));
JSON.删除(句柄);
JSON.删除(用户);
```

另有：`设置浮点数/对象` `获取浮点数/布尔/对象/数组` `是否包含键` `数组长度` `数组添加整数/浮点数/布尔/对象` `数组获取字符串/整数/…`。拼 JSON 一律用此 API 构建，别手拼字符串（引号转义易碎）。

## HTTP

客户端（reqwest 实现，真实网络）：

```qi
导入 标准库.HTTP;

变量 响应: 字符串 = HTTP.获取("https://example.com");        // GET
变量 回执 = HTTP.发送("https://api.example.com", "{\"a\":1}"); // POST(URL, 体)
// 更新=PUT 删除=DELETE 修补=PATCH；请求(方法, URL, 头, 体) 全定制
```

服务器（简单阻塞式；生产用 qi-web 框架）：

```qi
导入 标准库.HTTP;

常量 主机 = "127.0.0.1";
常量 端口: 整数 = 46271;    // 用 3000 以上随机高位端口，严禁 8080/3000/8000

函数 入口() {
    变量 服务器 = HTTP.创建服务器(主机, 端口);
    变量 请求 = HTTP.接受连接(服务器);   // 阻塞，返回原始请求文本
    打印行(请求);
    HTTP.关闭服务器(服务器);
}
```

## 网络（TCP/UDP）

```
TCP连接(主机, 端口, 超时ms) -> 句柄        TCP读取(句柄, 缓冲区大小) -> 字符串
TCP写入(句柄, 字符串) -> 写入字节数        TCP关闭(句柄)
TCP监听(主机, 端口, 队列) -> 句柄          TCP接受连接(句柄) -> 客户端句柄
UDP绑定(主机, 端口) -> 句柄               UDP发送到(句柄, 消息, 目标主机, 端口)
UDP接收(句柄, 缓冲区) -> 字符串           端口可用(端口) -> 1/0
获取本机IP() -> 字符串                    解析主机(域名) -> IP
```

注意 `TCP读取` 是两参（句柄、缓冲区大小），旧文档单参写法已过时。

## 数学（2026.07.12 起，底层 libm，全部收发 浮点数）


## 图形化（GUI，egui 控件层，2026.07.12 起）

immediate mode（每帧重画，程序自持全部控件状态：当前值传进去、新值收回来）。模块名 `标准库.图形化`（别名 GUI），惯用 `导入 标准库.图形化 作为 图形;`。完整示例 `qi/示例/图形界面/控件演示.qi`：

```qi
导入 标准库.图形化 作为 图形;

函数 入口() {
    变量 应用: 整数 = 图形.应用创建("演示", 720, 820);
    如果 (应用 == 0) { 打印行("GUI 运行时不可用"); 返回; }
    变量 计数: 整数 = 0;
    变量 名字: 字符串 = "";
    变量 音量: 整数 = 50;
    当 (图形.帧开始(应用) == 1) {              // 0 = 窗口已关
        图形.标题文本("控件演示");
        如果 (图形.按钮("点我 +1") == 1) { 计数 = 计数 + 1; }
        图形.标签("计数 = " + 整数转字符串(计数));
        名字 = 图形.输入框("名字", 名字);       // (id, 当前值) -> 新值
        音量 = 图形.滑条("音量", 音量, 0, 100);
        图形.进度条(音量);
        图形.帧结束(应用);
    }
    图形.关闭应用(应用);
}
```

25 个 FFI——生命周期：`应用创建(标题,宽,高)->句柄` `帧开始(句柄)->1/0` `帧结束(句柄)` `关闭应用(句柄)`；控件：`标签` `标题文本` `彩色标签(文本,r,g,b)` `按钮(文本)->点击1/0` `输入框(id,当前)->新值` `多行输入` `滑条(id,当前,最小,最大)->新值` `复选框(id,文本,当前)->1/0` `下拉选择(id,选项CSV,序号)->新序号` `进度条(0-100)` `折线图(id,值CSV,宽,高)` `消息弹窗(文本)`；布局：`分隔线` `空行` `水平开始/水平结束` `分组开始(标题)/分组结束`。

⚠️ **GUI 需要带 gui feature 的运行时**：`cd qi-runtime && cargo build --release --features gui`。默认构建是无 GUI 桩版（保持可 zig 交叉编译）——桩版下 `应用创建` 返回 0 并打「错误: GUI 库未安装」；**不带 feature 的重建会把同路径 .a 覆盖回桩版**。中文字体自动探测系统 CJK（PingFang/Noto/雅黑）。暂无滚动区域/表格；消息弹窗是即时浮窗非模态。

## 向量（数值计算，2026.07.04 起可用）

```qi
导入 标准库.向量;
// 元素必须写浮点字面量(1.0),整数字面量会推成整数数组 → FFI 读到垃圾

打印行("模 = " + 浮点数转字符串(向量.长度([3.0, 4.0])));    // 5
变量 单位 = 向量.归一化([3.0, 4.0]);                        // [0.6, 0.8]
变量 倍 = 向量.数乘(甲, 2.0);
打印行(浮点数转字符串(向量.余弦相似度(甲, 甲)));            // 1(平行)
```

维度不匹配/坏输入返回 0.0 或空数组(宁保守不崩,一次性 [qi-vector] 日志)。
